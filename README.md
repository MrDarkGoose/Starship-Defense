# Starship Defense

`Starship Defense` — це аркадна гра на `pygame`, у якій гравець керує зорельотом, знищує комети та захищає Землю від космічної загрози.

## Опис режимів

### Classic

`Classic` — це сюжетний режим.  
За задумом, гравець є останньою лінією оборони Землі. Із космосу до планети летять комети, а завдання пілота — відбивати їх за допомогою зорельота, не даючи їм прорватися до поверхні. Кожна знищена комета наближає гравця до перемоги, а кожна пропущена атака знову ставить Землю під загрозу.

У цьому режимі гра відчувається як місія із захисту планети:

- корабель патрулює орбіту Землі
- комети падають зверху і по діагоналі
- гравець стріляє автоматично та ухиляється від зіткнень
- мета — витримати атаку й зупинити хвилю комет

### Plus

`Plus` — це нескінченний режим.  
Тут уже немає акценту на завершенні місії, а основний упор зроблено на виживання, темп і набір очок. Комети продовжують летіти дедалі довше й щільніше, а гравцеві потрібно якомога довше триматися в бою, встановлювати рекорд і покращувати свій результат.

У цьому режимі:

- потік ворогів триває без зупинки
- складність поступово зростає
- важливі реакція, позиціонування та виживання
- головний результат — рекорд за кількістю знищених комет

## Що є в проєкті

- `starship_game.py` — базова версія гри
- `starship_game_plus.py` — розширена версія
- `sprite/` — спрайти, фон і снаряди

## Запуск

Встановіть `pygame`:

```bash
pip install pygame-ce
```

## Компіляція

Для збірки гри в один `.exe` файл без консольного вікна використовуйте `PyInstaller`:

Встановлення `PyInstaller`:
```bash
pip install pyinstaller
```
Компіляція гри:
```bash
pyinstaller --clean --noconfirm --onefile --windowed `
  --add-data "sprite\\bg_space.png;sprite" `
  --add-data "sprite\\comets.png;sprite" `
  --add-data "sprite\\space_battery.png;sprite" `
  --add-data "sprite\\starship.png;sprite" `
  --add-data "sprite\\laser\\bullet.png;sprite\\laser" `
  starship_game.py
```

Після компіляції готовий файл буде створено в директорії `dist/`:

- `dist/starship_game.exe`

## Керування

- `Стрілки` — рух корабля
- `SPACE` — рестарт після поразки або перемоги
- `ESC` — повернення назад або закриття гри

## Збереження

Для тестової `plus`-версії використовується окремий файл рекордів:

- основний файл: `test/test_starship_high_score.json`
- резервна копія: `Documents/starshipdefance/save/starship_high_score.backup.json`

Якщо основний файл видалено, гра може відновити дані з резервної копії.
